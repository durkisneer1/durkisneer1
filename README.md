### Kraken Engine

My main project is [Kraken Engine](https://github.com/Kraken-Engine/PyKraken),
a 2D game framework written in C++ with Python bindings.

It includes hardware-accelerated rendering, custom shaders, tilemaps,
audio, and other tools for making games. I spend a lot of time on
performance and making the Python API comfortable to use.
